## Referência rápida de offsets

Todos são offsets **na imagem de CD** (`.BIN` cru), como o manual os escreve.

| Offset | O que é | Seção |
| --- | --- | --- |
| `0xD37A` | trocar `8` por `9` faz o jogo parar na tela de boot (e voltar a `8` é obrigatório) | [9a](/docs/biblia-we2002/09-telas-de-inicio.md#9a--visualizando-o-boot-no-emulador) |
| `0x24D8` / `0x2E08` | texto do boot | [9c](/docs/biblia-we2002/09-telas-de-inicio.md#9c--editando-o-boot-via-editor-hexa-texto) |
| `0x2E08` | gráfico `.TMD` do boot | [9d](/docs/biblia-we2002/09-telas-de-inicio.md#9d--editando-o-boot-via-editor-hexa-gráfico) |
| `0x12D76FC` … `0x178AA48` | bloco de **todos** os uniformes 3D | [X](/docs/biblia-we2002/x-transferir-uniformes.md) |
| `0x2861B0` | ordem dos times no menu | [X1](/docs/biblia-we2002/x1-ordem-times-menu.md) |
| `0x25CA9C` | `78 0F` → `64 0F` destrava o menu Copas | [X3](/docs/biblia-we2002/x3-destravar-copas.md) |

Offsets de paleta citados nas telas de abertura: `17280` (gráfico 7 do
`LOGO.BIN`), `17344` (gráficos 8 e 9), `17120` (gráficos 1 e 2), `17088`
(gráficos 3 a 6).

## Sobre esta transcrição

- **O texto é o do PDF.** A ortografia foi normalizada (acentos e crases que o
  original perdeu), mas nenhuma instrução, offset, nome de arquivo ou número foi
  alterado. Onde o manual está errado ou incerto, ele continua errado aqui — é
  documento de 2002 sobre software de 2002.
- **Uma leitura foi decidida:** no offset `0x25CA9C` o PDF escreve `78 OF` e
  `64 OF`, com a letra **O**. Está transcrito como `78 0F` / `64 0F` (zero), que
  é o único par que faz sentido em hexadecimal.
- **As imagens** foram extraídas do próprio PDF (`pdfimages -png`) e vivem em
  [`img/`](img/), nomeadas `fig-<página>-<índice>.png`. São **69** — inclusive os
  ícones minúsculos de botão que o texto cita no meio da frase.
- **Nem toda ilustração do PDF virou arquivo.** Algumas eram desenho vetorial
  embutido, não bitmap, e o extrator não as vê: é o caso da captura do
  PPF-O-MATIC que o passo `4a` menciona ("a tela INFORMATION") e das setas e
  molduras desenhadas no Word. O texto que as descreve continua no lugar.
- **O aviso do autor** sobre a campanha *Adote um Time* e os créditos aos
  tutoriais de terceiros foram preservados na
  [seção 1](/docs/biblia-we2002/01-introducao.md).

> **Cuidado com este repositório:** o manual manda editar a imagem **in place**,
> e o `newWe2002` também. Trabalhe sempre sobre cópia — ver a seção de imagens de
> CD no [CLAUDE.md](../../CLAUDE.md).
