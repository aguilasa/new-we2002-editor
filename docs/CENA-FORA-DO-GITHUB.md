# A cena de WE2002 fora do GitHub

O [levantamento de 2026-08-09](/docs/ECOSSISTEMA-GITHUB.md) varreu o GitHub e
concluiu que quase nada de edição de WE2002 vive lá. Este arquivo é a outra
metade: os **links que o usuário quer guardar** de onde a cena de fato
publica — blog, YouTube, fórum. É uma lista de leitura, não um inventário
exaustivo, e cresce quando aparecer coisa.

> Nada aqui foi baixado nem executado. São links e o que a página diz de si.
> Nenhuma dessas ferramentas é oráculo de nada — a mesma ressalva que vale
> para o `make wte` no [CLAUDE.md](../CLAUDE.md).

---

## PasionWEMod / PasionWe

Blog e canal em espanhol, ativos: a página de ferramentas é de **dezembro de
2024** e o vídeo se anuncia como **de 2025**. É a evidência mais recente que
apareceu de que ainda se produz ferramenta nova para este jogo.

| Link | O que é |
|---|---|
| [Herramientas Edición](https://pasionwemod.blogspot.com/2024/12/herramientas-edicion.html) | O índice de download |
| [Herramienta Kits y Mcr para editar we2002 2025](https://www.youtube.com/watch?v=1vr0g3D8YmA) | O vídeo que mostra duas delas rodando |

O que a página indexa:

- **EasyMcr v4** — editor de memory card, com banco de dados local, busca de
  jogador no Transfermarkt e conversão a partir de eFootball. O `.MCR` é
  **formato irmão, não o mesmo** que a imagem de CD — a distinção está na
  seção 2 do [ECOSSISTEMA-GITHUB.md](/docs/ECOSSISTEMA-GITHUB.md).
- **Kits To We2002** v3, v3.2 e v3.4 (esta com preview) e **Kits2D tipo PES
  para we2002** — uniformes.
- **WE2002 Menu Team Names** — nomes de time no menu.
- **Winning Eleven Multi Tool 2K24**, do **CARP** — o mesmo Maximiliano Ducoli
  cujo [maxiducoli/WE2002-MultiTool](https://github.com/maxiducoli/WE2002-MultiTool)
  já está catalogado na seção 4 do ECOSSISTEMA. Vale como aviso geral: **o
  autor publicar no GitHub não quer dizer que a versão que a cena usa esteja
  lá**, e a recíproca também não vale.

**Por que interessa a este repositório.** Camisa, bandeira e nome de time são
território que o `newWe2002` já toca — são justamente as áreas que o editor do
Obocaman faz melhor e que o `ed.exe` não faz, conforme a seção do `make wte`
no [CLAUDE.md](../CLAUDE.md). Aqui o valor é o mesmo: **comparar interface e
garimpar ideia**, com a paridade com o `ed.exe` continuando a ser o critério.
