# 13-seis-linhas -- o EXPERIMENTO DISCRIMINANTE do `0x6500` (MCR-TASK-13).
#
# Poe as seis colunas da `malla2` em seis linhas DISTINTAS -- coluna c na linha
# c, para c de 0 a 5 -- aceita, e exporta o `.mcr`. Se os cinco cobradores
# saem 0,1,2,3,4 e o `0x6500` sai 5, o byte e escrito pela SEXTA coluna da
# mesma malha, aquela cujo rotulo o proprio editor chama de `Captain`.
#
# O par obrigatorio e o `13-controle.txt`: la a tela de tatica nao e aberta, e
# os seis bytes tem de sair como o jogo os gravou. Sem esse controle, seis
# valores distintos nao provam que foi a edicao que os pos ali.
#
#   rm -f work/oraculo-13-seis.mcr
#   bash wte/tools/golden_run_wte.sh tools/mcr/oracle/13-seis-linhas.txt \
#        work/wte-japanese-shift-jis.bin /tmp/oraculo-13
#   python3 tools/mcr/formation.py work/oraculo-13-seis.mcr
#
# A GEOMETRIA SAI DE `wte/re/zonas.md`, medida do `.text` e conferida contra o
# formulario: `malla2` em (368,312), 144x176, passo 24 x 16, folga 3 -- seis
# colunas e onze linhas. Clicar escolhe a COLUNA pelo X e move o marcador
# daquela coluna para a LINHA do Y. Centro da coluna c: 368 + 24c + 12.
# Centro da linha r: 312 + 16r + 8.
#
#   col 0 = SF (Short Foul Kick)      col 3 = LC (Left Corner Kick)
#   col 1 = LF (Long Foul Kick)       col 4 = PK (Penalty Kick)
#   col 2 = RC (Right Corner Kick)    col 5 = CP (Captain)
#

# e o rotulo dele diz `Captain`.
